# Interface direction

Extend the existing MiniCPM demo's dark operating interface: charcoal surfaces, indigo action controls, legible light text, and generous space around the avatar. The moving character is the primary content; controls and diagnostics remain secondary.

Use a single desktop workspace with avatar playback and a compact input/conversation column. On narrow screens these stack. Native system typography follows the existing demo. No marketing surface or decorative illustration.

Show loading, ready, listening, generating, interrupted, disconnected, and error states. Provide explicit start/stop and interruption controls, an accessible transcript, and optional camera input. Keep runtime details inside a collapsible diagnostics panel.
